# 24-hour timeline (T0 = challenge chosen)

Shift the clock to the event's own schedule (mentoring slots, midnight check, submission time). Internal deadlines sit at least 60 minutes before official ones.

| When | Who | What |
|---|---|---|
| T0 – T+0:30 | orchestrator | Collect every instruction source. Launch 2 blind decode reads (different models, max effort). Start the AI log. |
| during the briefing | all humans | Write down everything said that is not in the brief, verbatim; ask permission to record any company meeting |
| T+0:30 – T+1:00 | orchestrator + team | Reconcile `DECODED-BRIEF.md`; deliverables checklist; roles by strengths and accounts; repo + BOARD (ask the user before sharing protocol files) |
| T+1:00 – T+2:00 | orchestrator | Question tree + triage; ranked questions for the company/mentor slots |
| T+1:00 – T+4:00 | slice owners' agents | Wave 1 (T1 questions only), findings to the bus; digest rebuilt hourly |
| company / mentor slots | assigned humans | Ask ranked questions; fill the capture table; record answers as labelled verbal claims |
| T+4 – T+5 | orchestrator | Checkpoint 1: what changed the answer, what died; **pick the beachhead** |
| T+5 – T+8 | agents | Wave 2 deep on the beachhead; cross-verification of CRITICAL findings on another person's account |
| T+7 – T+9 | orchestrator (+ different-model red team) | Forge ideas, kill tests incl. (c) market-standard, persona red team, score; **lock the spine by T+9** (or before the midnight check, whichever is first) |
| midnight check / mentor feedback | humans | Show the spine + 3 numbers; write down every objection verbatim |
| T+9 – T+13 | builders | Pitch script, slides, one-pager draft; numbers copied from the ledger by ID |
| T+11 – T+15 | verifier agents on spare accounts | Fact-check at HIGH on the pitch source file; claim sheet |
| T+15 – T+17 | orchestrator + humans | Apply fixes; `numcheck` final files; 25 hard Q&A questions by persona |
| T+17 – T+20 | humans | Sleep in shifts. One person awake to run the verification agents |
| T+20 – deadline-1h | presenters | Two timed rehearsals under the limit; one-pager final; **submit one-pager at its internal deadline**, save the confirmation |
| last hour | presenters | Final run, Q&A drill, a 1-minute version without slides if there is an audience vote |
